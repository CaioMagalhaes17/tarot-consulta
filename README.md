# Site de Consulta Tarológica

## Descrição do Projeto

Este projeto é um site simples de consulta tarológica desenvolvido com **React** e **Tailwind CSS**.

## Objetivo

O site serve para:
- Exibir informações da pessoa que realiza a consulta tarológica
- Redirecionar o usuário para o WhatsApp para contato

## Características

- **Simplicidade**: O projeto não possui complexidades como:
  - Sistema de login/autenticação
  - Sistema de solicitações
  - Sistema de pagamentos
  - Outras funcionalidades complexas

- **Foco**: Apenas apresentação de informações e redirecionamento para WhatsApp

## Tecnologias

- **React**: Framework JavaScript para construção da interface
- **Tailwind CSS**: Framework CSS para estilização

## Estrutura

O projeto foi inicializado com Vite e TypeScript, proporcionando uma base moderna e eficiente para desenvolvimento.
